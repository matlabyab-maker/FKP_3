FKP_3 v1.49

1. دکمه ± با لمس طولانی، کشویی زیرگونه‌ها را باز می‌کند. موارد درخواستی شامل ±، ∓، §، ≤، ₱، ≥، ~، ฿، ی و € به همراه چند شکل مرتبط تایپوگرافی اضافه شده‌اند.
2. نمایش و ساختار این زیرگونه‌ها مشابه منوی لمس طولانی حرف «ا» است.
3. پنجره کنترل موس بر اساس تصویر ارسالی بازطراحی شد و قابلیت‌های قبلی مانند حرکت، کلیک چپ/راست، Drag، Auto Snap، Resize، شفافیت، Quick Settings و بستن حفظ شدند.
4. دکمه ↕ سمت چپ برای تغییر اندازه نشانگر موس بین چهار اندازه استفاده می‌شود.
5. دکمه ↕ سمت راست برای فعال/غیرفعال کردن ذره‌بین محل نشانگر استفاده می‌شود؛ در Android 11+ تصویر بزرگ‌نمایی‌شده محل نشانگر نمایش داده می‌شود.
6. دکمه Select حالت انتخاب/Drag را فعال یا غیرفعال می‌کند.
7. رویداد Drag پنجره به‌صورت مصرف‌شده نگه داشته می‌شود تا لمس Drag به کنترل‌های زیر پنجره منتقل نشود.
8. نسخه پروژه به 1.46 ارتقا یافت و workflow مستقل FKP_3 برای Build Debug APK اضافه/اصلاح شد.

وضعیت Build محلی:
در محیط فعلی Android SDK و Gradle نصب نیست و دسترسی شبکه برای دریافت آن‌ها وجود ندارد؛ بنابراین APK واقعی در این محیط ساخته و تأیید نشده است. Workflow آماده است تا در GitHub Actions Build واقعی را انجام دهد.
